# DKU Haji & Umrah

Website PT Dayakindo Kalimantan Utama (DKU) untuk layanan Haji & Umrah di Samarinda. Seluruh halaman dirender secara statis tanpa dependency build.

## Menjalankan lokal

Jalankan server statis dari folder ini, misalnya:

```powershell
python -m http.server 4173
```

Lalu buka `http://localhost:4173`.

## Halaman

- Beranda
- Paket Umrah
- Detail Paket
- Tentang Kami
- Galeri
- Artikel
- Kontak

Semua nama, harga, tanggal, foto, dan informasi bisnis pada template ini adalah konten demo/ilustratif.
